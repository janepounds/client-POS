A lightweight, offline-first **Point of Sale (POS) system** built with **Electron**, designed for small businesses to manage sales, inventory, and transactions efficiently on a laptop or desktop.  

---

## 🚀 Features

- **Offline-First POS** – Fully functional without internet connectivity.  
- **Sales Management** – Add, edit, and complete sales transactions.  
- **Inventory Tracking** – Keep track of products, stock, and pricing.  
- **Receipt Generation** – Print or save receipts directly.  
- **Multi-User Support** – Manage multiple employees with roles (optional).  
- **Data Persistence** – Uses local database (SQLite) for storage.  
- **User-Friendly Interface** – Clean, intuitive design for fast operations.
